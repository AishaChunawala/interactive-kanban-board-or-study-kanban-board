# 📋 Interactive Kanban Task & Study Board

An interactive, responsive Kanban board built with pure **Vanilla JavaScript**, **HTML5 Drag & Drop API**, and **CSS Grid**. Designed for tracking study goals and project workflows with persistent storage.

🚀 **Live Demo:** [View Live App](https://aishachunawala.github.io/interactive-kanban-board-or-study-kanban-board/)

---

## ✨ Features
- **Drag & Drop Workflow:** Effortlessly move tasks between *To Do*, *In Progress*, and *Completed* columns using native browser HTML5 Drag and Drop attributes (`draggable="true"`).
- **Persistent Data:** Tasks automatically save to `localStorage` so state persists across browser reloads.
- **Full CRUD Functionality:** Create, edit inline, and delete task cards dynamically.
- **Dynamic Counters:** Real-time badge indicators displaying active task counts per column.
- **Responsive Layout:** Built with CSS Grid and flexbox for clean scaling across display sizes.

---

## 🛠️ Tech Stack
- **Structure:** HTML5 (Semantic Markup)
- **Styling:** Modern CSS3 (CSS Grid, Custom Properties, Flexbox)
- **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation, Event Delegation)
- **Storage:** Browser `localStorage` API
